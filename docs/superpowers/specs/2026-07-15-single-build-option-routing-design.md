# 单配置方案直达详情设计

## 目标

当 AI 装机接口只返回一套可用配置时，跳过“选择配置方案”页面，直接进入配置详情页；只有存在多个方案时才让用户选择。

## 路由规则

- 返回 1 套方案：直接展示该方案的配置详情。
- 返回 2 套及以上方案：展示“选择配置方案”页面。
- 返回 0 套方案：不自动进入详情，保留现有错误与空结果处理边界。

该规则适用于所有预算档，不写死 3000 元。

## 返回行为

- 单方案详情点击返回：回到 AI 装机需求填写页。
- 多方案详情点击返回：回到方案选择页。
- 方案选择页点击返回：回到 AI 装机需求填写页。

## 实现位置

- `AIBuildFlowRules` 提供可测试的单方案判断规则。
- `AIBuildFlowView` 继续拥有接口响应、已选方案和页面切换状态。
- 请求完成时由 `AIBuildFlowView` 根据方案数量同时设置响应和已选方案。
- `BuildOptionsView` 仅在方案数量大于一时创建，避免单方案流程短暂闪出选择页。

不在 `BuildOptionsView.onAppear` 中模拟点击，也不修改后端响应结构。

## 现有改动边界

`ContentView.swift`、`AIBuildView.swift` 和 `AIBuildFlowRulesTests.swift` 当前存在未提交的生成动画改动。实现必须在这些改动之上追加，不能覆盖或回退它们。

## 验证

- 规则测试覆盖 0、1、2 个方案的判断结果。
- 源代码规则测试锁定单方案直达和返回到需求页的路由分支。
- 运行 iPhone 17 Simulator 的 Debug 与 Release 构建。
- 视觉验收由用户完成。
