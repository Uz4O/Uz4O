# AI 装机结果页参考图改版设计

## 目标

将 AI 装机结果页改为参考图中的清晰层级：顶部方案主视觉、下方无外层卡片的八大件清单，让标题、总价、配件型号和单件价格成为页面重点。

## 页面结构

1. 保留现有返回导航、页面标题和合规提示。
2. 使用黑色主视觉方案卡展示短标题、简短说明、配置总价和主机图片。
3. 配件清单直接放在页面背景上，不再使用包裹整张清单的白色卡片。
4. 清单底部展示价格波动提示。
5. 页面底部继续保留“保存配置单”。

不恢复“复制清单”，不新增分享、重新生成或继续优化操作。

## 主视觉方案卡

- 使用现有 `PCTower` 透明主机图片，不新增图片资源。
- 卡片使用接近黑色的纯色背景和不超过 20 点的圆角。
- 左侧展示动态短标题：高帧率游戏配置、大型游戏配置或均衡游戏配置。
- 标题下方展示面向小白的单行短说明：
  - 高帧率：优先保证高帧率游戏体验
  - 大型游戏：优先保证大型游戏画质与流畅度
  - 均衡：兼顾高帧率与大型游戏
- 左下角展示“配置总价”和动态总价。
- 主机图片位于右侧，不遮挡文字。

## 配件清单

- 标题仅显示“配件清单”，右侧不显示复制操作。
- 每行使用黑色图标底座、配件类别、全新或二手标签、型号和右对齐价格。
- 型号和价格保持最高视觉层级，类别和成色为辅助信息。
- 型号最多两行，价格固定宽度，不与长型号重叠。
- 各行之间使用细分隔线，不增加独立卡片。

## 数据边界

- 继续使用现有 `BuildPlan` 和 `PCPart` 动态数据。
- 为结果标题对应的短说明增加明确映射，不使用后端内部解释文案。
- 不修改后端 API、模板、价格或兼容性逻辑。

## 验证

- 扩展 `BuildResultContentRulesTests`，锁定黑色主视觉卡、无清单外层卡片、动态短说明、价格提示、保留保存按钮和不出现复制按钮。
- 运行 iPhone 17 Simulator 的 Debug 与 Release 构建。
- 视觉验收由用户完成。
