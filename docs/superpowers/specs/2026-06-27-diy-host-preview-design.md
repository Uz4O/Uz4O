# DIY 主机概况预览设计

## 目标

用户完成自由选配后，可在当前“开始 DIY”页面查看所选机箱与机箱风扇组合的现成主机效果图。图片由后端提供，不使用 AI 生成，也不在客户端合成。

## 初始页面

- 页面初始状态严格保持“开始 DIY”参考图布局。
- 标题说明与八张硬件卡片之间不预留图片区域，也不展示空状态预览卡。
- 页面底部保留“查看主机概况”按钮，作为唯一的图片加载入口。

## 硬件选择结构

- 页面保持八张硬件卡片的 4×2 布局：CPU、显卡、主板、内存、硬盘、电源、散热、机箱。
- 第 07 项继续显示为“散热”。进入该项后，用户分别选择 CPU 散热器和机箱风扇方案。
- CPU 散热器参与整机配置与兼容性判断，但不参与主机图片查询。
- 主机图片仅由 `机箱 ID + 机箱风扇方案 ID` 唯一匹配。

## 查看主机概况

1. 用户点击“查看主机概况”。
2. 若机箱或机箱风扇方案尚未选择，页面提示用户先完成这两项，不请求后端。
3. 若两项均已选择，页面请求后端返回对应组合的完整效果图 URL。
4. 加载期间，标题说明与硬件卡片之间插入与最终图片等高的加载占位，避免页面二次跳动。
5. 加载成功后，主机图片显示在标题说明与八张硬件卡片之间，页面自动滚动到图片顶部。
6. 底部按钮文字切换为“收起主机概况”；点击后移除图片区域并恢复原始布局。

## 状态失效规则

- 用户修改机箱或机箱风扇方案后，已显示的旧图片立即收起，按钮恢复为“查看主机概况”。
- 用户修改 CPU、显卡、主板、内存、硬盘、电源或 CPU 散热器时，当前主机图片继续保留。
- App 不展示与当前机箱和机箱风扇不匹配的旧图片。

## 错误与缺图

- 后端没有对应组合时，图片位置显示“暂未收录该外观组合”，并引导用户更换机箱或机箱风扇方案。
- 网络加载失败时，图片位置显示简短失败提示和“重新加载”按钮。
- 缺图和网络失败不影响硬件选配、兼容性检测或预算统计。

## 范围边界

- 本阶段不使用 AI 生成图片。
- 本阶段不在客户端叠加机箱和风扇图片。
- 本阶段不新增独立主机概况页、全屏大图、分享或保存图片功能。
- “AI 优化”按钮与主机图片预览是两项独立能力。

## 验证

- 验证初始状态无图片占位且与参考图布局一致。
- 验证未选择机箱或机箱风扇时不会发起图片请求。
- 验证正确的机箱与风扇 ID 组合用于查询，并显示后端返回图片。
- 验证修改机箱或风扇后旧图收起，修改其他硬件时图片保留。
- 验证缺图、网络失败、重新加载和收起状态。
