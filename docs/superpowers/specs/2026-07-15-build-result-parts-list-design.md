# AI 装机结果页配置清单精简设计

## 目标

让用户进入配置结果页后，优先看到每个配件的型号和价格，并能快速确认配件是全新还是二手。

## 页面范围

- 保留页面标题、精简方案摘要、配置总价和“保存配置单”。
- 方案摘要使用“高帧率游戏配置”“大型游戏配置”或“均衡游戏配置”，不展示内部模板名称、生成逻辑或用户原始预算。
- 仅精简“配件清单”区域。
- 不修改后端模板、价格数据或兼容性判断。

## 配件行布局

每个配件行只展示以下信息：

1. 配件类别和图标，用于快速定位 CPU、主板、显卡等类型。
2. 配件型号，作为左侧最醒目的主信息。
3. 配件价格，右对齐并加粗，与型号共同构成视觉重点。
4. “全新”或“二手”标签，作为辅助信息放在型号附近。

删除以下展示内容：

- “成色：”文字前缀。
- 价格来源和 CSV/Markdown 文件名。
- 参考价格日期。
- 配件选择理由、替代型号和其他说明。

## 视觉规则

- 使用紧凑的双层配件行，减少上下留白。
- 型号允许换行，价格保持稳定右对齐。
- 全新/二手使用低干扰的小标签，不抢占型号和价格的视觉层级。
- 保留分隔线，方便连续扫描八大件。

## 数据与验证

- `PCPart` 明确携带全新/二手展示值，不从说明文字中解析。
- API DTO 和后端响应不变。
- 增加聚焦规则测试，验证真实配置映射只保留正确的成色值。
- 使用 iPhone 17 模拟器完成 Debug 构建验证。
