# M.2 散热装甲宽度与 DIMM 避让调整

## 目标

将主板 M.2 散热装甲的宽度缩小约 9%，使其视觉比例更紧凑，同时仍完整覆盖 M.2 SSD。将整组 M.2 安装区向左平移 0.70 个 Blender 单位，消除接口外壳与 DIMM 底部卡扣的穿模。

## 约束

- 仅收窄散热装甲的横向宽度。
- 保持散热装甲的长度、厚度、中心位置和动画节点名不变。
- 保持 SSD 模型尺寸和安装锚点不变。
- 调整后散热装甲宽度必须仍大于 SSD 宽度，两侧保留少量覆盖余量。
- M.2 槽、凹槽、导向板、散热装甲及其饰面必须同步平移，保持彼此相对位置。
- 不修改 DIMM 插槽、卡扣或内存安装动画。

## 验证

- 脚本语法检查通过。
- 尺寸断言确认散热装甲仍宽于 SSD。
- 包围盒断言确认 M.2 接口外壳与最近 DIMM 卡扣之间存在正间隙。
- Blender 重新导出 USDC。
- iOS 项目编译、安装并启动到 iPhone 17 Pro Max 模拟器。
