# 显卡厂商与预算利用率优化设计

## 目标

优化装机 Skill、显卡白名单、基底模板和后端筛选规则：默认优先 NVIDIA，按光追需求决定是否提供 AMD 方案，并要求每套配置充分使用用户预算。

## 预算硬规则

每套可返回配置必须满足：

```text
用户预算 <= 配置总价 <= 用户预算 + 300 元
```

- 不再返回低于用户预算的方案。
- 显卡下一档无法放入 `预算 + 300` 时，保留当前显卡并把预算用于有实际收益的其他配件。
- 不为了凑预算购买明显过度的主板、散热器或无需求的外观件。
- 没有合理组合进入区间时，该方案标记为不可用。

## 显卡选择矩阵

### 5000 元以下

- 不询问光追。
- 不设置固定厂商规则。
- 根据光栅性能、价格、整机平衡和预算完成度在 A/N 卡中选择。

### 5000 元及以上 FPS

- 不询问光追。
- NVIDIA 优先。
- 仅在 NVIDIA 组合无法进入预算区间，或同价 AMD 光栅性能高至少约 15% 且不会影响用户需求时，允许 AMD 作为回退。

### 5000 元及以上 3A 或均衡

- 用户开启光追：全新、二手、混合采购分别返回一套 NVIDIA 方案，最多三套。
- 用户不开光追：全新、二手、混合采购分别返回 NVIDIA 与 AMD 方案，最多六套。
- 前端未传光追偏好：按 NVIDIA 优先处理，保持当前 App 行为稳定。

## 显卡白名单

- RTX 4060 全新卡恢复可选，全新参考价为 `¥2100`。
- RTX 4060 Ti 全新参考价虽然为 `¥2300`，但与 RTX 5060 过于接近，因此移出全新可选白名单。
- RTX 4060 Ti 二手卡继续保留。
- 现有 RTX 30 系二手矿卡风险规则继续生效。

## 剩余预算优化顺序

显卡无法合理升档时，只进行有实际收益的升级：

1. 满足功耗、散热、容量和兼容性底线。
2. FPS 方向优先升级 CPU，再考虑内存、硬盘和电源品质。
3. 3A 方向优先确认 GPU 已达到当前可用最高档，再升级内存、硬盘、CPU 和电源品质。
4. 均衡方向在 CPU、内存、硬盘和电源之间选择实际收益最高的一项。
5. Wi-Fi/蓝牙、主板接口和机箱外观只在用户提出对应需求时占用预算。

## 模板与 API 数据结构

- `BuildTemplateDetails` 增加 `gpu_vendor: nvidia | amd`。
- `BuildRequest` 预留可选光追偏好；未提供时保持 NVIDIA 优先。
- 5000–20000 元的 3A/均衡方向，在每个采购方式下增加 AMD 副方案。
- 预计增加 186 套模板：31 个价位档 × 2 个方向 × 3 种采购方式。
- 模板总量预计从 297 增加到约 483，实际数量以生成器可行性检查为准。
- `/v1/build/options` 根据光追偏好、采购方式和 GPU 厂商筛选，前端最多接收六套方案。

## 分阶段实施

### 第一阶段

- 更新装机 Skill 和参考规则。
- 更新显卡价格及全新/二手资格。
- 更新高低预算生成器、模板数据和后端筛选结构。
- 前端不新增光追问题；请求未提供光追偏好时继续返回 NVIDIA 优先方案。

### 第二阶段

- 在 5000 元及以上的 3A/均衡流程增加光追问题。
- 将用户选择传给后端。
- 开光追展示最多三套 NVIDIA 方案，不开光追展示最多六套 N/A 方案。

## 验证

- 单元测试覆盖显卡厂商矩阵、4060/4060 Ti 资格和预算区间。
- 生成制品验证每套总价位于 `[预算, 预算 + 300]`。
- 验证全新模板不含 RTX 4060 Ti，二手模板仍可包含。
- 验证 RTX 4060 全新参考价为 `¥2100`。
- 后端全量测试通过后，才允许更新生产模板。
