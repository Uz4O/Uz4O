# AI 装机助手产品执行方案 v1

## 1. 核心定位

第一阶段把产品收敛成一个中立、可信、可复制给别人确认的 AI 装机建议工具。

产品优先服务不懂电脑、想买主机的小白用户。第一阶段不做购买渠道、不做导购、不接商家链接。

一句话定位：

> 不懂电脑也能拿到一份具体、能解释、能发给别人确认的主机配置建议。

第一阶段主要解决四件事：

- 帮用户从零生成主机配置。
- 帮用户看商家或朋友给的配置单有没有坑。
- 帮用户保存自己的电脑配置，后续用于升级建议。
- 输出能发给朋友、群友、商家确认的配置文案。

## 2. 登录后分流流程

登录完成后，不直接进入首页，先做轻量分流。

### 2.1 第一页：是否已有电脑

页面标题：

> 你现在有正在使用的电脑吗？

选项一：

**没有，想配一台新电脑**

进入 App 首页，首页重点展示：

- AI 一键装机
- 帮我看配置单
- 装机指南
- 我的配置单

选项二：

**有，想记录/升级我的电脑**

进入“我的电脑档案”录入页。用户填完或跳过后进入首页。

这类用户首页重点展示：

- 旧电脑升级方案
- 我的电脑档案
- 配置排雷
- 兼容性检测

必须保留一个跳过入口：

**先跳过，进入 App**

原因：很多小白不知道自己电脑配置，如果强制填写，会在第一步流失。

## 3. 装机偏好选择

分流后增加一页装机偏好。

页面标题：

> 你希望电脑更偏哪种风格？

建议提供三个选项。

### 3.1 均衡推荐

默认选项。

文案：

> 性能和外观都照顾一点，适合大多数人。

### 3.2 性能优先

文案：

> 同预算优先把钱花在 CPU、显卡、内存、电源上，外观简单实用。

### 3.3 颜值优先

文案：

> 更重视白色主机、海景房机箱、灯效和整体观感，但系统会提醒你不要为了颜值牺牲核心性能。

这个偏好需要保存，并影响后续 AI 配置结果和旧电脑升级建议。

## 4. 首页调整

首页右下角原本被图片资源占用的卡片，建议改成一个真实功能入口。

推荐入口：

**帮我看配置单**

副标题：

> 粘贴商家报价，看看有没有坑

这个入口和“AI 一键装机”形成两个最重要路径：

- 没有配置：AI 一键装机
- 已经有人给配置：帮我看配置单

首页第一阶段建议保留四个核心入口：

- AI 一键装机
- 帮我看配置单
- 旧电脑升级方案
- 装机指南

“自由 DIY 装机”可以保留，但不建议放在首页最核心位置，因为它更适合懂电脑的人。

## 5. AI 一键装机流程

主流程：

```text
预算 -> 用途 -> 偏好 -> 是否接受二手 -> 生成配置
```

关键规则：

- 预算范围覆盖 3000-50000+。
- 默认预算只包含主机。
- 不包含显示器、键鼠、系统、桌椅、音箱等外设。
- 预算允许小幅浮动，建议默认 ±5%。
- 默认只推荐全新配件。
- 只有用户明确选择接受二手后，才出现二手方案。
- 具体型号来自人工推荐库，AI 只负责组合和解释。

预算文案要明确写成：

> 主机预算

结果页和复制文案里也要明确：

> 本方案仅包含主机硬件，不含显示器和外设。

## 6. 配置结果页

结果页必须分三层展示。

### 6.1 第一层：小白结论

用简单话告诉用户这套配置适合什么、有没有明显问题。

示例：

> 这是一套 8000 元左右的 2K 游戏主机，显卡优先，适合主流 3A 和网游。预算主要花在显卡和电源上，没有明显高 U 低显问题。

### 6.2 第二层：完整商品型号配置单

每个配件显示：

- 配件类别
- 完整商品型号
- 参考价
- 为什么选它
- 注意事项

示例：

```text
CPU：AMD Ryzen 5 7500F
主板：微星 B650M MORTAR WIFI
显卡：影驰 RTX 4070 Super 金属大师
电源：长城 X6 金牌 650W
```

### 6.3 第三层：可复制给别人确认

提供三个动作：

- 复制配置单
- 复制小白说明
- 复制给朋友确认

复制文案要像微信里能直接发出去。

示例：

```text
预算约 8000 元，仅主机，不含显示器和外设。
主要用途是 2K 游戏。
这套配置显卡优先，没有明显高 U 低显，电源留了余量。
麻烦帮我看看有没有明显问题。
```

## 7. 推荐库策略

第一阶段采用：

> 人工推荐库 + AI 解释

不让 AI 随便编型号。

推荐库按以下维度组织：

- 预算档：3000 / 4000 / 5000 / 6000 / 8000 / 10000 / 12000 / 15000 / 20000 / 30000 / 50000+
- 用途：网游 / 3A 游戏 / 办公 / 剪辑 / 游戏兼办公
- 偏好：均衡 / 性能优先 / 颜值优先
- 购买偏好：全新 / 接受显卡二手 / 接受部分二手
- 风险标签：价格波动大 / 不建议小白买 / 二手需谨慎 / 电源不能缩水

建议第一阶段重点打磨 3000-15000 预算区间。

20000+ 也可以支持完整商品型号，但需要增加提示：

> 高端配置建议购买前再次确认用途、价格和兼容性。

## 8. 二手配件策略

默认不推荐二手。

只有用户明确选择接受二手后，才出现二手方案。

建议选项：

- 不接受，只要全新
- 只接受显卡二手
- 能接受部分二手

如果结果里出现二手配件，必须给醒目风险提示。

示例：

> 二手显卡建议选择支持验货的平台，注意矿卡、维修卡、无保修等风险。小白用户不建议私下交易。

复制给别人确认的文案里也要自动带上二手风险。

## 9. 我的电脑档案

用户选择“我已经有电脑”后进入“我的电脑档案”。

第一阶段字段不要太复杂：

- CPU
- 显卡
- 内存
- 硬盘
- 电源
- 主要用途

每个字段都要允许“不知道”。

用户只填一部分也可以保存。后续升级建议可以提示：

> 当前缺少电源和主板信息，补充后升级建议会更准确。

录入完成后，App 记住这台电脑。后续升级页基于这份档案判断：

- 当前瓶颈
- 哪些配件值得保留
- 优先升级什么
- 升级预算怎么花最值

## 10. 配置排雷功能

首页新增的“帮我看配置单”进入配置排雷流程。

第一阶段只需要用户粘贴配置单或报价。

示例输入：

```text
i7-14700F + RTX4060 + H610 主板 + 500W 电源，商家报价 6999
```

输出分三块：

### 10.1 小白结论

示例：

> 不建议直接买，主要问题是 CPU 太高、显卡偏弱、主板和电源偏保守。

### 10.2 问题列表

示例：

- 高 U 低显：CPU 预算过高，显卡偏弱。
- 主板偏低：H610 搭配高功耗 CPU 不适合长期稳定使用。
- 电源风险：500W 勉强可用，但建议换一线 650W 金牌。
- 报价偏高：同类配置可能有 800-1200 元溢价。

### 10.3 可复制回复

示例：

```text
这套配置有高 U 低显问题。
i7-14700F 搭配 RTX4060 对游戏用户不太均衡，建议降低 CPU，把预算加到显卡上。
主板和电源也偏保守，购买前建议重新调整配置。
```

## 11. 第一阶段先不做

为了避免产品发散，第一阶段暂时不做：

- 购买链接
- 商家推荐
- 自动比价
- 社区论坛
- 复杂硬件百科
- 多套复杂 DIY 对比
- 过度专业参数筛选
- 让 AI 完全自由生成配件型号

这些功能以后可以做，但第一阶段会稀释核心体验。

## 12. 执行优先级

### P0：必须先做

- 登录后分流页
- 装机偏好选择页
- 首页右下角改为“帮我看配置单”
- AI 结果页三层结构：小白结论、完整型号配置单、可复制文案
- 推荐库基础结构

### P1：紧接着做

- 我的电脑档案
- 旧电脑升级基于档案生成建议
- 二手配件风险提示
- 预算只含主机的明确说明

### P2：后续增强

- 多预算档推荐库扩充
- 高端配置二次确认机制
- 配置单分享图片
- 配置历史版本
- 用户反馈配置是否靠谱，并反向优化推荐库

## 13. 成功标准

第一阶段做完后，用户应该能完成三个闭环：

1. 我没有电脑，输入预算和用途，拿到一套具体主机配置。
2. 我拿到别人给的配置单，粘贴进去，知道有没有坑。
3. 我可以一键复制配置单和解释，发给朋友或群里确认。

这三个闭环跑通，产品第一阶段就成立。
