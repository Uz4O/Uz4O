# 登录后选择界面方案 v1

## 1. 目标

用户登录完成后，不直接进入首页，而是先通过一个轻量选择流程，让 App 了解用户当前状态。

这个流程只解决两个问题：

1. 用户现在有没有正在使用的电脑。
2. 用户更偏向性能、颜值，还是均衡推荐。

选择完成后，App 再根据用户情况进入首页，并优先展示更适合他的功能。

## 2. 流程结构

登录成功后进入两步选择流程：

```text
登录成功 -> 是否已有电脑 -> 装机偏好 -> 进入 App 首页
```

如果用户不想填写，必须允许跳过：

```text
登录成功 -> 跳过 -> 进入 App 首页
```

## 3. 第一步：是否已有电脑

### 页面标题

```text
先了解你的情况
```

### 页面说明

```text
我们会根据你是否已有电脑，优先显示更适合你的功能。
```

### 选项一：我要配一台新电脑

适合用户：

- 还没有自己的电脑配置。
- 想从零开始配一台主机。
- 想用 App 帮自己生成装机建议。
- 想拿别人给的配置单来排雷检测。

推荐卡片文案：

```text
我要配一台新电脑
还没有配置，想从零获得装机建议
```

用户选择后：

- 记录用户状态为“新电脑用户”。
- 进入下一步“装机偏好选择”。
- 进入首页后，优先展示和新装机相关的功能。

### 选项二：我已经有电脑

适合用户：

- 已经拥有自己的电脑。
- 想记录当前电脑配置。
- 想后续判断旧电脑哪里值得升级。
- 想知道哪些配件还能继续用。

推荐卡片文案：

```text
我已经有电脑
记录当前配置，后续帮你判断怎么升级
```

用户选择后：

- 记录用户状态为“已有电脑用户”。
- 后续可以引导用户填写自己的电脑配置。
- 进入下一步“装机偏好选择”。

### 跳过入口

页面底部保留：

```text
先跳过，进入 App
```

跳过后的处理：

- 不记录明确用户状态。
- 直接进入 App 首页。
- 首页使用默认展示方式。

保留跳过的原因：

- 小白用户可能不知道自己有没有完整配置。
- 有电脑的用户也可能暂时不想填写。
- 不能让选择流程变成登录后的阻碍。

## 4. 第二步：装机偏好选择

### 页面标题

```text
你希望电脑更偏哪种风格？
```

### 页面说明

```text
这个偏好会影响后续配置建议，你也可以之后再修改。
```

### 选项一：均衡推荐

默认选项。

适合用户：

- 不知道自己该选性能还是颜值。
- 希望电脑既实用，也不要太丑。
- 大多数普通用户。

推荐卡片文案：

```text
均衡推荐
性能和外观都照顾一点，适合大多数人
```

### 选项二：性能优先

适合用户：

- 更关心游戏帧率。
- 更关心剪辑、渲染、生产力效率。
- 不想把太多预算花在灯效和外观上。

推荐卡片文案：

```text
性能优先
同预算优先把钱花在 CPU、显卡、内存和电源上
```

### 选项三：颜值优先

适合用户：

- 更喜欢白色主机、海景房机箱、灯效。
- 希望主机摆在桌面上更好看。
- 愿意为外观分配一部分预算。

推荐卡片文案：

```text
颜值优先
更重视外观，但会帮你避开好看却不值的搭配
```

### 默认策略

默认选择：

```text
均衡推荐
```

原因：

- 小白用户不一定能判断性能和颜值的取舍。
- “均衡推荐”最不容易让用户选错。
- 性能党和颜值党可以主动切换。

## 5. 选择完成后的首页差异

### 新电脑用户首页重点

如果用户选择“我要配一台新电脑”，首页应优先展示：

- AI 一键装机
- 帮我看配置单
- 装机指南
- 我的配置单

首页表达重点：

```text
从零帮你生成一套能看懂、能发给别人确认的装机建议。
```

### 已有电脑用户首页重点

如果用户选择“我已经有电脑”，首页应优先展示：

- 旧电脑升级方案
- 我的电脑档案
- 配置排雷
- 兼容性检测

首页表达重点：

```text
记录你的当前电脑，后续帮你判断哪里值得升级、哪些配件还能继续用。
```

### 跳过用户首页

如果用户点击“先跳过，进入 App”，首页使用默认展示。

默认首页建议优先展示：

- AI 一键装机
- 帮我看配置单
- 旧电脑升级方案
- 装机指南

## 6. 后续可延展点

这次选择流程只做轻量判断，不要求用户马上填写复杂信息。

后续可以在用户选择“我已经有电脑”后，再引导填写“我的电脑档案”。

电脑档案第一阶段建议只问：

- CPU
- 显卡
- 内存
- 硬盘
- 电源
- 主要用途

每个字段都要允许选择：

```text
不知道
```

这样可以避免小白用户因为不知道配置而放弃使用。

## 7. 产品原则

- 先分流，不做复杂问卷。
- 先问用户有没有电脑，再问偏好。
- 装机偏好不要只做“颜值党 / 性能党”二选一，必须保留“均衡推荐”。
- 默认选“均衡推荐”。
- 必须允许跳过。
- 用户选择后可以后续修改。
- 这个流程的目标是降低首页理解成本，而不是增加登录门槛。
