# 首页 UI 升级指令（去"小程序感" → 现代简约高级感）

> 目标：把首页从"白底 + 飘浮白卡 + 2×2 宫格 + 纯黑白"的小程序观感，升级为现代简约、有品牌质感的 App 首页。
> 风格定调：**现代简约 / 高级感**（保留浅色基调，靠主色、布局、信息密度、克制的质感取胜，不做深色科技风）。
> 范围：主要改 `May/May/Screens/HomeView.swift` 和 `May/May/Theme/AppTheme.swift`；不改导航、不改业务逻辑、不动后端。

---

## 病根诊断（为什么现在像小程序）

1. **零品牌色**：`AppTheme` 全是黑白灰，`primaryButton` 是深蓝黑。没有 accent color。
2. **2×2 功能宫格**：`featureRows` 把 4 个功能平铺成田字格——这是小程序最典型布局。
3. **白卡 + 图标飘右下角 + 大片留白**：`HomeFeatureCard`（HomeView.swift:204-250）信息密度低，显空。
4. **大虚软阴影**：`AppTheme.cardShadow`（半径 24）是小程序标配的飘浮感。

---

## 任务 1：引入品牌主色（AppTheme.swift）

在 `AppTheme` 增加一套主色系（推荐沉稳的"科技靛蓝"，高级且适合工具类）：
```swift
// 品牌主色（靛蓝，高级感、专业）
static let accent = Color(red: 0.29, green: 0.36, blue: 0.92)        // #4A5CEB 主色
static let accentSoft = Color(red: 0.93, green: 0.94, blue: 1.0)     // 主色的极浅背景版
static let accentGradient = LinearGradient(
    colors: [Color(red: 0.33, green: 0.40, blue: 0.96),
             Color(red: 0.46, green: 0.34, blue: 0.93)],
    startPoint: .topLeading, endPoint: .bottomTrailing
)
```
> 主色用在：主按钮、选中态、强调数字、功能图标点缀。**不要全局滥用**——高级感来自"克制地用一点主色"，大部分仍是中性色。

再收紧阴影，去掉飘浮感：
```swift
static var cardShadow: some ViewModifier {
    ShadowModifier(color: Color.black.opacity(0.05), radius: 12, x: 0, y: 4)  // 更收敛、更实
}
```

## 任务 2：打破 2×2 宫格 → 主次分明的布局（HomeView.swift）

把"4 个等大卡片田字格"改成有层次的结构：

**方案**（推荐）：
- **AI 一键装机**：保留顶部大 Hero 卡（已经是主角，很好）。
- **其余 4 个功能**（性能测试 / 排雷 / 升级 / 指南）：从 2×2 等大宫格，改成**纵向的横条列表**（每行一个功能，左图标 + 右文字 + 末尾箭头），或 **1 大 + 3 小** 的不对称网格。
- 横条列表是更"App"的做法，信息密度高、不像宫格。每行高度约 72-80pt。

> 若用横条列表：图标在左（48×48 圆角方块、用主色或主色浅背景），中间标题+副标题左对齐，右侧一个 chevron。行与行之间用极淡分隔或小间距。

---

## 任务 3：功能卡"填实"，去掉飘角图标（HomeFeatureCard）

当前 `HomeFeatureCard` 图标孤零零浮在右下角、大片留白。改为信息密集、左对齐的结构：
- 图标移到**左上或左侧**，做成**实心填充图标 + 主色浅背景方块**（`accentSoft` 底 + `accent` 图标），不要再用白到灰的渐变方块飘在右下。
- 标题加粗、副标题紧跟其下。
- 可在副标题位置加一个**有意义的小标签/数据**增加信息量（如排雷："帮 1.2 万人避坑"；升级："按预算排序"）——文案可用占位，由用户后续替换。
- 卡片去掉大软阴影，改用**1px 极淡描边 + 收敛阴影**（更高级、更实）。

---

## 任务 4：社区模块做成"信息流卡片"（HomeCommunitySection）

当前社区那条偏列表项。升级为一张**完整帖子预览卡**：
- 整张卡有轻微背景/描边，内含：作者头像+昵称+时间、帖子摘要（2 行）、底部互动数据（赞/评论/收藏，图标用主色点缀）。
- "进入社区"做成右上角次级入口。
- 让它像即刻/小红书的 feed 卡，而非纯文字行。

---

## 任务 5：整体精修（细节决定高级感）

- **标题区**："AI 装机助手" + 铃铛，可保留，但铃铛加一个未读小红点会更有 App 感（可选）。
- **间距**：拉开模块间距（section 之间留更多呼吸感），高级感来自留白节奏，不是塞满。
- **圆角统一**：卡片圆角统一到 16-18，别忽大忽小。
- **字重对比**：标题更重、正文更轻，加大层次对比。
- **去掉纯白卡叠浅灰底的廉价感**：卡片可用纯白 + 极淡描边，或非常微妙的中性渐变，避免"白卡飘在灰底上"。

---

## 不要做的事

- ❌ 不改底部导航（原生 TabView 保留）。
- ❌ 不改任何点击跳转逻辑、不改 `action(for:)`、不动 `profile.homeFeatureOrder` 的数据结构。
- ❌ 不接后端、不动业务数据（继续用现有 mock 占位）。
- ❌ 不要引入深色背景（这次是浅色高级感方向）。
- ❌ 主色不要滥用到刺眼——克制是高级感的关键。
