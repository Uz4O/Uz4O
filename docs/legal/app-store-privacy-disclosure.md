# App Store 隐私披露填写清单

核验日期：2026-06-28

本文件用于填写 App Store Connect 的 App 隐私问卷。发布前必须基于最终构建包、后端生产配置和第三方控制台重新核验。

| App Store 类别 | 当前数据 | 与用户关联 | 用于追踪 | 用途 | 代码依据 |
| --- | --- | --- | --- | --- | --- |
| 联系信息 | 手机号 | 是 | 否 | App 功能、账号管理 | `backend/app/auth/models.py` |
| 用户内容 | 自由文本备注、保存的配置方案 | 是 | 否 | App 功能 | `backend/app/builds/ai_provider.py` |
| 标识符 | Apple 用户标识、内部账号 ID | 是 | 否 | App 功能、账号管理 | `backend/app/auth/models.py` |
| 购买项目 | 不收集 | 不适用 | 否 | 不适用 | 当前版本无交易接口 |
| 使用数据 | 不用于追踪的必要功能状态 | 视生产日志配置 | 否 | App 功能、安全 | 发布前日志核验 |
| 诊断 | 仅必要安全日志；无崩溃 SDK | 视生产日志配置 | 否 | 安全、诊断 | 发布前日志核验 |

## 当前结论

- 不将任何数据用于跨 App、跨网站追踪。
- 当前代码未集成广告 SDK。
- 当前上线版本不提供公开发布内容功能。
- 手机号、账号标识、自由文本备注和保存方案可能与账号关联。
- 自由文本备注可能包含用户主动输入的内容，产品将提示用户不要提交无关敏感信息。
- AI、短信、云、崩溃和统计服务商确定后，必须重新核验其数据收集及 App Store 披露要求。

## 提交前复核

- [ ] 使用代理或网络日志核对最终安装包的全部域名。
- [ ] 核对所有 SDK 的 Privacy Manifest 和数据用途。

- [ ] 核对 App Store Connect 答案与本表及隐私政策一致。
- [ ] 由运营者孙裕凤确认后提交。
