## 使用规则

- 全新配置：只能选有全新参考价的主板。
- 二手/混合配置：可以选二手参考价，但必须提示二手主板保修、针脚、暗病风险。
- AM4 低预算：A520M-K 偏省钱；B450M/B550M 重炮手偏更稳，但按停产二手处理。
- AM5 入门：PRIME B650M-K 用于 7500F/9600X 等无需堆供电的性价比方案。
- AM5 中端：B650M PLUS 重炮手、B850M 迫击炮、B850M POWER、B850M AYW OC 是主要选择。
- AM5 高端：X870E 战斧导弹、刀锋钛用于高预算或扩展需求。
- 顶级板：ROG X870E NEO / 吹雪 / DARK HERO / ACE MAX / GODLIKE MAX / EXTREME / GLACIAL 只用于极高预算、颜值或用户点名。
- LGA1851 办公平台只服务于 15 代 Core Ultra 200S 白名单 CPU，不为 13/14 代 CPU 新增主板。
- PRIME B860M-K 主要搭配 Ultra 5 245K；PRO B860M-A WIFI 默认搭配 245K、250 Plus、265K；MAG B860M MORTAR WIFI 优先搭配 265K、270 Plus 的持续高负载方案。
- 两张微星主板已经集成 Wi-Fi，满足无线需求时不得再加 50 元或重复追加 `WIFI` 后缀。
