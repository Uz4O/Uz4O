## 核心原则落实

后端严格遵守规划文档里的核心原则：AI 不能自由发明硬件型号。

具体做法：

- 硬件型号必须来自维护中的硬件库。
- 价格必须来自人工复核后的参考价格。
- 推荐池和配置模板必须人工审核后发布。
- DeepSeek 只能在后端给定的候选 `component_id` 中选择。
- AI 返回结果会再次经过兼容性规则复校。
- 候选数据不足时返回待生成/未就绪状态，不编造配置。

## 已完成的主要后端能力

### 1. FastAPI 后端脚手架

- 建立 FastAPI 应用结构。
- 增加健康检查、测试基础、部署脚本和 PM2 启动配置。
- 独立部署到 `/opt/new-site`，端口 `8790`，PM2 名称 `new-site`。

### 2. 数据库与硬件库

- 接入 PostgreSQL 配置。
- 建立硬件组件表、价格表、账户表、配置模板、保存方案、社区等核心数据模型。
- 从现有 Swift 硬件目录导入后端硬件库。
- 将 `detail` 拆成结构化规格字段，用于兼容性、升级和性能估算。
- 增加硬件目录分页和价格查询接口。

### 3. 价格摄取

- 支持导入人工确认后的 `approved-reference-prices.csv`。
- 只把人工审核通过的价格写入参考价库。
- 保留来源、价格区间、通过/拒绝计数和审核时间。

### 4. 规则与兼容性引擎

- 实现 CPU/主板插槽匹配。
- 实现主板和内存代际匹配。
- 实现电源瓦数余量判断。
- 实现 CPU/GPU 失衡、主板档次等风险判断。
- 提供统一兼容性检查接口。

### 5. 账户、登录与配置同步

- 支持短信验证码登录基础流程。
- 支持 Onboarding 偏好同步。
- 支持当前电脑配置同步。
- 支持保存、查看和删除装机方案。
- 增加验证码限流、旧验证码失效、格式校验、重复验证码冲突修复。
- 增加 Sign in with Apple 后端校验流程，未配置 Apple 参数时安全拒绝。

### 6. AI 一键装机

- 支持人工配置模板优先匹配。
- 支持推荐硬件池和人工价格库的规则兜底。
- 支持 DeepSeek 受控候选选择。
- 支持外部 AI 失败后自动降级到规则兜底。
- 防止 AI 返回候选池外型号。
- 装机接口已兼容前端字段：
  - `useCase`
  - `gameCategories`
  - `officeApps`
  - `purchasePreference`
  - `chassisColor` / `chassisColorPreference`
  - `cpuPreference`
  - `gpuPreference`
  - `specifiedCPU`
  - `specifiedGPU`
- DeepSeek 测试 Key 已在服务器配置并通过连通性测试；文档和接口不暴露 Key 原文。

### 7. 配置排雷

- 支持配置单文本分析。
- 支持硬件型号归一和参考价对比。
- 支持规则风险输出。
- 支持可给商家看的回复话术。
- 增加流式响应和缓存。

### 8. 升级建议

- 根据当前电脑配置、预算和硬件性能指标生成升级建议。
- 支持预算和输入边界校验。
- 增加流式响应和缓存。

### 9. 游戏性能测试

- 基于 CPU/GPU 性能指标、游戏和分辨率估算 FPS。
- 返回平均帧、低帧、瓶颈和建议。
- 对输入数量和字段长度做边界限制。

### 10. 社区服务

- 支持社区 Feed、详情、发帖、评论、点赞、收藏。
- 支持作者展示和作者查询优化。
- 支持敏感内容变体拦截。
- 支持图片上传签名入口。
- 支持 OSS 直传签名逻辑，未配置 OSS 时安全拒绝。
- 限制标签、配件字段、图片类型、图片大小和文件扩展名一致性。

### 11. 装机指南内容服务

- 提供装机指南静态内容接口。
- 返回配件认识、装机步骤和前端互动安装所需元数据。

### 12. 运行、安全与成本控制

- 高成本接口限流。
- 社区写入限流。
- Redis 分布式限流通道和故障降级。
- 请求体积上限。
- 敏感接口禁止缓存。
- 基础安全响应头。
- CORS 白名单和危险 CORS 阻断。
- 生产 API 文档默认关闭。
- 登录 token 异常格式和超长 token 安全拒绝。
- 高成本接口用量、缓存命中、AI 失败次数和成本统计。
- AI Provider URL 安全阻断，只允许外部 HTTPS 地址。
- 健康检查不暴露密钥，只返回配置状态。
